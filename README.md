FocusFit AI — Study Space, Tuned to You 🎯

💡 About the Project

FocusFit AI is a responsive web application designed to help students create a study environment that matches their individual preferences, study tasks, and focus habits.

Instead of offering generic study advice, FocusFit AI generates a personalized, practical study-space plan with clear explanations for each recommendation.

🎯 The Problem

Students have different study preferences, tasks, and environmental needs. However, study advice often assumes that the same environment works for everyone.

This can make it difficult for students to identify practical changes that may help them focus.

💻 Our Solution

FocusFit AI provides an interactive questionnaire that uses students’ preferences to generate a personalized study plan.

The recommendations cover:

* 🔊 Sound environment
* 💡 Lighting and desk setup
* ⏱️ Study-session rhythm
* 🌿 Adjustments based on estimated room noise

The application also explains why each recommendation was selected and allows users to copy their plan for later use.

⚙️ How It Works

1. The student answers a short questionnaire.
2. The application processes the selected preferences.
3. A local recommendation engine generates a personalized plan.
4. The student reviews the explanations and can copy the plan.

The prototype uses a transparent, rule-based recommendation engine implemented in JavaScript. It does not currently use a trained machine-learning model or an external generative AI API.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

✨ Key Features

* Interactive study-preference questionnaire
* Personalized study-space recommendations
* Adjustable room-noise estimate
* Explainable recommendations
* Copy-plan functionality
* Responsive design for mobile and desktop
* No account required
* No microphone recording
* No personal information stored by the prototype

🚀 How to Run the Project

1. Clone or download this repository.
2. Open index.html in a modern web browser.
3. Answer the questionnaire.
4. Generate and review your personalized focus plan.

No installation, build process, or API key is required.

🌍 Intended Impact

FocusFit AI aims to help students turn general study advice into practical actions they can test in their own study environments.

By making recommendations explainable and easy to adjust, the project encourages students to explore which environmental settings work best for their individual needs.

🔒 Responsible Design

* The application does not record audio.
* Room noise is estimated by the user rather than measured automatically.
* Recommendations are suggestions, not medical advice.
* The prototype does not claim that one study environment is best for everyone.

⚠️ Current Limitations

FocusFit AI is an early-stage prototype. Its recommendations are based on predefined rules rather than a trained AI model. The effectiveness of its recommendations has not yet been scientifically validated.

🔮 Future Improvements

* Test recommendations with consenting student participants.
* Collect optional feedback to evaluate recommendation usefulness.
* Explore privacy-conscious personalization techniques.
* Evaluate whether a validated machine-learning model could improve recommendations.
* Investigate optional sound-level measurement with explicit user permission.
